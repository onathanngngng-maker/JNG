# Paper Gen

Generate similar university past papers and matching suggested solutions from uploaded reference files.

The uploaded past paper and suggested solution are the templates. Keep layout, structure, marks, and command words (close variants only). Keep solution format and detail: the same "Solution n:" working lines as the upload, not program code, and no marking scheme. Questions, numbering, marks, and calculated values must match.

Final deliverable is **PDF**.

**Pagination:** Follow the original paper: one question per page stays one per page; two on a page stays two on a page; continue a question on the next page if the original does. The suggested solution follows the uploaded solution the same way: one question's solution per page stays one per page, and a solution that continues keeps that page break.

**Images:** Copy figures/diagrams from the uploaded paper onto the matching generated page. Do not drop or redraw them. A question with a figure keeps the object shown in that image: Phosphorus stays Phosphorus. Change calculation numbers that are not printed on the figure. If the figure shows only letters such as L and D, change the numbers given for those letters. Keep negative powers, such as \(10^{-19}\) and \(10^{-31}\). A question with no figure changes the named object to another of the same kind (Palladium-103 may become another isotope) and changes the calculation numbers. Each generation uses a different set of calculation numbers. The worked solution must use those new numbers, and the arithmetic must come out correctly. A waiting time that is a whole number of half-lives stays a whole number of half-lives.

**Math:** Use LaTeX-style notation (`\(\Delta v\)`, \(\theta\), \(\pi r^2\), \(\frac{a}{b}\), \(\mathrm{m\,s^{-2}}\)). Do not write symbols as plain words when proper notation is available.
